# 构建说明

仓库里没有 Gradle、没有 Android SDK 时的打包方式。整条链路只依赖 **JDK + build-tools 里的两个 jar**，不依赖 `aapt2`（它只有 x86-64 版本，arm64 设备上跑不起来）。

## 目录

```
index.html                          页面本体（单文件，双击即可用）
app/落筒录入_v1.38.apk               打好签名的安装包
源码/android/MainActivity.java       WebView 外壳
源码/android/AndroidManifest.xml     清单的文本形式（实际由脚本生成二进制版本）
源码/打包/make_apk.py                组装 APK
源码/打包/axmlwrite.py               AndroidManifest → 二进制 AXML
源码/打包/res_table.py               生成 resources.arsc（多密度图标）
源码/图标/gen_icon.py                由母版生成 5 档密度图标
源码/图标/ic_launcher_master_512.png 图标母版（512×512）
```

## 外壳做了什么

- `assets/index.html` 通过 `shouldInterceptRequest` 映射到虚拟源 `http://app.local/`，
  用 http 源而不是 `file://`，是为了让 `localStorage` 稳定可用（页面数据全存在里面）
- `WebSettings.FORCE_DARK_OFF`：系统切深色时页面不反色，固定浅色
- 状态栏、导航栏固定白色，图标深色（`LIGHT_STATUS_BAR` / `LIGHT_NAVIGATION_BAR`）
- `requestWindowFeature(FEATURE_NO_TITLE)`：去掉标题栏
- 返回键先让 WebView 回退，回不去才退出
- 网络资源拦截用具名内部类 `AssetClient`，不用匿名内部类（旧版 d8 会崩）

## 构建步骤

准备（一次性）：

1. JDK。注意：**d8 在 JDK 25 上会抛 NullPointerException**，必须用 JDK 17 或更低
2. Android build-tools（取 `lib/d8.jar`、`lib/apksigner.jar`）
3. `platform-34/android.jar`

编译与打包：

```bash
# 1. Java 编译（用 --release 8，不要同时给 -bootclasspath）
javac --release 8 -encoding UTF-8 -cp $AJ -d out/classes 源码/android/MainActivity.java

# 2. 转 dex
java -cp $BT/lib/d8.jar com.android.tools.r8.D8 \
    --release --min-api 21 --lib $AJ --output out/dex out/classes/**/*.class

# 3. 图标：母版 → 5 档密度
python3 源码/图标/gen_icon.py        # 输出 mipmap-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi

# 4. 资源表
python3 源码/打包/res_table.py       # 生成 out/resources.arsc，5 个 density 配置

# 5. 组装
python3 源码/打包/make_apk.py

# 6. 签名
java -jar $BT/lib/apksigner.jar sign \
    --ks keystore.jks --ks-key-alias luotong \
    --ks-pass pass:**** --key-pass pass:**** \
    --out out/app_signed.apk out/app.apk
```

## 图标必须做多密度

母版是 512×512。**不要只放一张 192px 到 mipmap-xhdpi**——
xhdpi 的标准尺寸是 96px，560dpi 的机器会把它放大 1.75 倍，图标明显发虚。
正确做法是 5 档各放一张，由系统按屏幕密度挑选：

| 目录 | 标准尺寸 |
|---|---|
| mipmap-mdpi | 48px |
| mipmap-hdpi | 72px |
| mipmap-xhdpi | 96px |
| mipmap-xxhdpi | 144px |
| mipmap-xxxhdpi | 192px |

## 几个必须知道的坑

1. **AXML 属性必须 20 字节**：`ns(4) name(4) rawValue(4) + Res_value(8)`，
   `attributeStart=20 attributeSize=20`。少写 `rawValue` 会让后面所有属性名错位。
2. **UTF-16 字符串要 `\0\0` 收尾**，否则解析器报 `not null terminated`。
3. **属性名要排在字符串池最前**，并与 resource map 等长对应，否则系统读不到 `android:` 属性。
4. **`ResTable_package.name` 是 char16[128] = 256 字节**，按 128 写会让整个包体偏移全错。
5. **`resources.arsc` 必须不压缩 + 4 字节对齐**（Android 11+），用 `res/raw/pad.bin` 占位微调。
6. **`configChanges` 是 flags 整数**不能给字符串；当前值 `0x0DB0`
   = `keyboardHidden|orientation|screenLayout|screenSize|smallestScreenSize|uiMode`。
7. **`pm install` 读 `/storage/...` 会失败**（`fuse:s0` 权限），必须先 `cp` 到 `/data/local/tmp/` 再装。
8. **`android:theme` 不要用字符串写 `@android:style/...`**，系统解析不了；去标题栏用 Java 的 `FEATURE_NO_TITLE`。
