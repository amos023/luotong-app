# 构建说明

仓库里没有 Gradle、没有 Android SDK 时的打包方式。整条链路只依赖 **JDK 17 + build-tools 里的两个 jar**，不依赖 `aapt2`（它只有 x86-64 版本，arm64 设备上跑不起来）。

## 目录

```
index.html                       页面本体（单文件，双击即可用）
app/落筒录入_v1.89.apk            打好签名的安装包
源码/android/MainActivity.java    WebView 外壳
源码/android/AndroidManifest.xml  清单的文本形式（实际由脚本生成二进制版本）
源码/打包/make_apk.py             组装 APK
源码/打包/axmlwrite.py            AndroidManifest → 二进制 AXML
源码/打包/res_table.py            生成最小 resources.arsc（只为图标）
源码/图标/gen_icon_白色筒身.py     第一套图标（筒身）
源码/图标/gen_icons_时间系列.py    第二套图标（时间主题，当前使用 2 号）
```

## 外壳做了什么

- `assets/index.html` 通过 `shouldInterceptRequest` 映射到虚拟源 `http://app.local/`，
  用 http 源而不是 `file://`，是为了让 `localStorage` 稳定可用（页面数据全存在里面）
- `WebSettings.FORCE_DARK_OFF`：系统切深色时页面不反色，固定浅色
- 状态栏、导航栏固定白色，图标深色（`LIGHT_STATUS_BAR` / `LIGHT_NAVIGATION_BAR`）
- `requestWindowFeature(FEATURE_NO_TITLE)`：去掉标题栏
- 返回键先让 WebView 回退，回不去才退出

## 构建步骤

准备（一次性）：

1. JDK 17（aarch64）解压到任意目录，记作 `$JAVA_HOME`
2. Android build-tools（取 `lib/d8.jar`、`lib/apksigner.jar`），记作 `$BT`
3. `platform-34/android.jar`，记作 `$AJ`

编译与打包：

```bash
# 1. Java 编译
$JAVA_HOME/bin/javac -encoding UTF-8 -source 8 -target 8 \
    -bootclasspath $AJ -d out/classes 源码/android/MainActivity.java

# 2. 转 dex
$JAVA_HOME/bin/java -cp $BT/lib/d8.jar com.android.tools.r8.D8 \
    --release --min-api 21 --lib $AJ --output out/dex out/classes/**/*.class

# 3. 生成图标与资源表（可选，换图标时跑）
python3 源码/图标/gen_icons_时间系列.py
python3 源码/打包/res_table.py

# 4. 组装
python3 源码/打包/make_apk.py

# 5. 签名
$JAVA_HOME/bin/java -jar $BT/lib/apksigner.jar sign \
    --ks debug.keystore --ks-key-alias luotong \
    --ks-pass pass:luotong123 --key-pass pass:luotong123 \
    --out out/app_signed.apk out/app.apk
```

## 几个必须知道的坑

1. **AXML 属性必须 20 字节**：`ns(4) name(4) rawValue(4) + Res_value(8)`，
   `attributeStart=20 attributeSize=20`。少写 `rawValue` 会让后面所有属性名错位。
2. **UTF-16 字符串要 `\0\0` 收尾**，否则解析器报 `not null terminated`。
3. **属性名要排在字符串池最前**，并与 resource map 等长对应，否则系统读不到 `android:` 属性。
4. **`ResTable_package.name` 是 char16[128] = 256 字节**，按 128 写会让整个包体偏移全错。
5. **`resources.arsc` 必须不压缩 + 4 字节对齐**（Android 11+），用 `res/raw/pad.bin` 占位微调。
6. **`configChanges` 是 flags 整数**不能给字符串；当前值 `0x0DB0`
   = `keyboardHidden|orientation|screenLayout|screenSize|smallestScreenSize|uiMode`。
7. **`pm install` 读 `/storage/...` 会失败**（`fuse:s0` 权限），必须先 `cp` 到 `/data/local/tmp/` 再装。
